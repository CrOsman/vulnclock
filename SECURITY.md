# Security policy

## Reporting a vulnerability

Please report vulnerabilities in VulnClock privately, not in a public issue:

- GitHub: **Security → Report a vulnerability** in this repository (private vulnerability reporting), or
- e-mail: info@3dtechlab.hr, subject "VulnClock security".

Tell us the version or commit, what you found and how to reproduce it. We confirm receipt within 3 working days, keep you informed while we fix it, and credit you in the advisory unless you prefer not to be named.

## Supported versions

Security fixes go into the latest release and the moving `v0` tag that the GitHub Action uses.

## How fixes are published

Fixed vulnerabilities are published as GitHub security advisories in this repository once a release with the fix is out.
